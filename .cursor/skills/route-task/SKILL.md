# Route a task

1. Read `repos/catalog.md`.
2. Match the request to one repository by name, topic, or language. If two entries both fit, name both and say which one you would use.
3. Check whether that repository is cloned in the current environment.
4. If it is cloned, do the work there and leave this home unchanged unless the catalog itself needs an update.
5. If it is not cloned, report the repository URL and stop. Ask for the next agent to be started with that repository in the environment. Do not copy the project into this home.
